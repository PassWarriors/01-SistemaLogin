# 🔐 Sistema de Login

Projeto desenvolvido na disciplina de **Programação Orientada a Objetos (POO)**.

O objetivo do sistema de login é identificar o usuário, levando o mesmo para uma tela de seleção. Onde ele pode selecionar entre uma **Agenda de Contatos** ou o **PassGuardian**. 

## 🔑 Autenticação

Nesta versão, a autenticação é utilizando um usuário e senha **FIXOS**.
| Usuário | Senha |
|---|---|
| `root` | `toor` |
